# MergeBot AI
An AI-powered PDF merging tool that extracts text, summarizes content, and merges PDFs efficiently.  

## 🚀 Features  
- 🔍 **Extracts Text:** Converts PDFs into searchable text using OCR.  
- ✨ **AI Summarization:** Generates a smart summary of merged PDFs.  
- 📂 **Merges Multiple PDFs:** Combine multiple PDFs into a single file.
